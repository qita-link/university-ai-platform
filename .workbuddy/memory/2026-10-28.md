# 2026-10-28

## 项目运行验证（campus-ai-platform）

- 后端：Spring Boot 3.4.13 + MyBatis-Plus 3.5.14 + Flyway(V1–V6) + Spring Security JWT；前端：Vue 3 + Vite 8 + TS。
- 环境坑位与结论：
  1. **JDK**：系统只有 JDK 27（D:\Java），Lombok 1.18.42 在 JDK 27 下 javac 编译报 `ExceptionInInitializerError: com.sun.tools.javac.tree.EndPosTable`。已在 `.localrun/jdk-17.0.20.1+1` 放置 Temurin 17（清华镜像下载，免安装），构建时 `JAVA_HOME` 指向它即通过。
  2. **Maven 中央仓库不可达**（repo.maven.apache.org 超时），阿里云镜像可用。使用 `.localrun/settings-aliyun.xml`（`-s` 指定，不改全局 settings），仓库目录 `.localrun/m2repo`。
  3. **MySQL80 服务无法启动**（当前用户非管理员，`net start` 拒绝访问；D:\mysql\sqldata\Data 权限属于 NetworkService）。改用项目内独立实例：`.localrun/mysql-data`，`mysqld --initialize-insecure` 后以 `--port=3306 --mysqlx=0` 前台启动。root 密码设为 5656550，创建 `campus` 用户与 `campus_ai` / `campus_ai_test` 库。
  4. **SERVER_PORT 继承宿主**：WorkBuddy 宿主进程把 `SERVER_PORT=52901`（其自身占用）传给子进程，导致应用起在 52901 并报端口占用。启动时必须显式 `SERVER_PORT=8080`。
  5. **前端 node_modules 是 Linux 下安装的**：`.bin` 只有 POSIX 符号链接（无 .cmd），且 `@rolldown/binding-win32-x64-msvc` 为空目录 → `vue-tsc`/`vite` 无法执行。用 `npm install --registry=https://registry.npmmirror.com` 修复（npmjs 不可达，npmmirror 可用）。
- 验证结果：mvn package 成功；单测 68、集成 137（`-Pit`，TEST_DB_PASSWORD=5656550）全通过；冒烟脚本 5/5；health UP；登录/鉴权/论坛写入/中文 ngram 检索/AI 降级（insufficientEvidence）均正常；前端 typecheck + build + vitest 14 通过，dev server 与 /api 代理联调 OK。
- 遗留：系统 MySQL80 服务仍需管理员启动（`net start MySQL80`，用 D:\mysql\sqldata\my.ini，root 密码若非 5656550 需改）；接入系统服务后建议删除 `.localrun` 临时实例，或保留作开发专用实例（3306 冲突）。
